BrowserBox V1.0 完整开发方案
1. 项目名称
BrowserBox
2. 项目定位
开发一款 Windows 本地浏览器环境管理工具。
核心用途：
管理多个独立浏览器环境
每个环境独立浏览器 Profile
每个环境独立 Cookie
每个环境独立缓存
每个环境独立 LocalStorage / IndexedDB / Session
每个环境绑定独立代理
支持 HTTP / HTTPS / SOCKS4 / SOCKS5 代理
支持代理用户名和密码
支持批量创建环境
支持批量导入代理
支持环境克隆
支持环境导入/导出
支持浏览器版本管理
支持浏览器更新
支持代理检测
支持环境分组、标签、搜索
支持同时运行多个浏览器环境
本项目不是浏览器内核项目。
不开发 Chromium 内核。
不修改 Chromium 源码。
浏览器使用官方 Chrome for Testing。
 
⸻
 
3. 技术栈
3.1 操作系统
Windows 10 / Windows 11 x64
第一版本只支持 Windows。

3.2 桌面框架
Electron

3.3 前端
Vue 3

Vite

Electron Main Process + Node.js
所有文件、浏览器、代理、进程管理操作都在 Main Process 完成。
Renderer 不允许直接访问文件系统。

4. 项目目录
用户第一次运行软件时选择安装/数据目录。
例如：
D:\BrowserBox
完整结构：
D:\BrowserBox │ ├── BrowserBox.exe │ ├── Browser │   ├── 138 │   ├── 139 │   ├── 140 │   └── … │ ├── Profiles │   ├── env_xxxxxxxxx │   ├── env_xxxxxxxxx │   └── … │ ├── Config │   ├── settings.json │   ├── environments.json │   ├── proxies.json │   ├── groups.json │   └── tags.json │ ├── Downloads │ ├── Logs │   ├── app.log │   ├── proxy.log │   └── environments │ ├── Temp │ ├── Backup │ └── Extensions
所有 BrowserBox 相关数据必须保存在用户指定目录。
不能把 Profile、Cookie、代理配置等偷偷保存到：
%APPDATA%
%LOCALAPPDATA%
桌面
我的文档
等其他位置。
Electron 本身必要的系统级缓存除外，业务数据必须统一保存到用户指定的数据目录。

每个环境明确指定浏览器版本。

11. 环境编号规则

002
003
…

新建：

不要自动重新占用 001。
可以在高级设置中提供“重新整理编号”，但默认不改变历史编号。

↓
上游代理
↓
Internet

23. 本地代理端口
每个运行中的环境分配独立本地端口。
例如：
环境001：
127.0.0.1:30001
环境002：
127.0.0.1:30002
环境003：
127.0.0.1:30003
端口动态分配。
不要写死。
启动时从端口池中寻找可用端口。
 
⸻
 
24. Local Proxy 要求
Local Proxy Engine 必须支持：

HTTPS CONNECT
SOCKS4
SOCKS5

HTTP Username/Password
代理连接超时
代理断线
代理错误
端口释放
环境关闭自动停止
 
⸻
 
25. 不要自己重新实现成熟代理协议
Local Proxy Engine 可以使用成熟的开源代理库。
不要为了简单而重新实现完整 SOCKS5/HTTP Proxy 协议。
重点是：
BrowserBox 负责代理生命周期管理。
代理库负责网络协议。
 
⸻
 
26. Chrome 连接代理
Chrome 使用：
127.0.0.1:30001
而不是直接使用：
user:pass@remote-ip:port
这样统一由 Local Proxy Engine 管理上游认证。

116. 给 AI 编程助手的开发要求
请严格按照本方案开发 BrowserBox。
开发原则：
不要擅自增加数据库。
不要把 Profile 保存到系统 AppData。
不要依赖用户已经安装的 Chrome。
不要修改 Chromium 源码。
不要自己实现 Chromium。
不要把 Cookie 单独复制出来管理。
不要把代理密码明文写入配置。
不要让 Renderer 直接访问 Node.js。

不要让同一个环境同时启动两个 Chrome。
不要删除正在使用的浏览器版本。

所有模块必须职责单一。
所有关键功能必须有错误处理和日志。
代码必须使用 TypeScript。
UI 使用 Vue3。
Electron 主进程负责系统级操作。
Renderer 只能通过 IPC 调用 Main Process API。
第一阶段先实现基础功能，再逐步增加高级功能。
